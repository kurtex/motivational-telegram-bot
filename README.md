# Motivational Telegram Bot

This is a simple Telegram bot designed to send daily motivational quotes to help users start their day on a positive note. The bot sends a random quote from a predefined list of motivational phrases at a scheduled time (e.g., 9 AM) to the user's chat.

## Features

- **Daily Motivational Quotes**: Sends a new motivational quote every day at a set time (e.g., 9 AM).
- **Customizable Quotes List**: Easily update the list of quotes in the code or an external file.
- **No User Interaction**: The bot does not currently allow users to request quotes on demand. It sends them automatically at the scheduled time.
